# Smart Banking Queue System (SBQS)

Smart Banking Queue System is an enterprise banking queue management and appointment booking platform.

## Technology Stack

- Frontend: Angular
- Backend: Java Spring Boot
- Database: PostgreSQL
- Cache: Redis
- IAM: Keycloak
- BPMN: Camunda
- Reporting: JasperReports
- Deployment: Docker Compose
